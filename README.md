# Sample-login-form
Responsive Login Form built using HTML and CSS, featuring a clean user interface, responsive navigation, profile section, username/password fields, remember-me option, forgot-password link, and mobile-friendly design.

🛠️ Technologies Used
HTML5
CSS3
CSS Media Queries


📱 Responsive Design

The login form is designed to work across:
💻 Desktop
💻 Laptop
📱 Tablet
📱 Mobile phones

Media queries are used to adjust the navigation, form layout, image size, typography, spacing, and buttons according to the screen size.

🎯 Purpose
This project was created to practice HTML structure, CSS styling, Flexbox, responsive design, form elements, and media queries.
